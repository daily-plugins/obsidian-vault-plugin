# 플러그인 아이콘 에셋

단순한 라벤더 아이콘만 Obsidian Vault Plugin의 브랜드 버전으로 사용합니다.

- `obsidian-vault-simple.svg`: 512 × 512 벡터 캔버스, 1,593바이트.
- `obsidian-vault-simple.png`: 256 × 256 RGBA PNG, 6,800바이트.

네 개의 단색 라벤더 면(#AA8AF5)을 투명한 간격으로 구분했습니다. 배경 타일, 채팅 배지, 그라데이션, 그림자, 체크무늬는 없습니다. 두 파일 모두 10,000바이트 미만입니다. PNG는 `@resvg/resvg-js`로 SVG에서 렌더링했습니다.

각 면의 경로는 다음 공식 에셋을 기반으로 합니다.
https://obsidian.md/images/obsidian-logo-gradient.svg

브랜드 가이드라인: https://obsidian.md/brand (2026년 9월 28일 확인).
Obsidian의 이름, 로고, 앱 아이콘은 상표입니다. 이 아이콘은 개인 사용을 위한 비공식 변형이며 Obsidian 또는 OpenAI의 승인을 의미하지 않습니다. 가이드라인은 개인적인 앱 아이콘 변경을 허용하며 상업적 사용 시 Obsidian에 문의하도록 안내합니다. 상업적으로 배포하기 전에 허용 범위를 확인하세요.
